# Underseen legal site

This folder contains the public-facing pages needed for the app-store submission:

- `privacy/` — privacy policy
- `terms/` — terms of use
- `support/` — support and troubleshooting
- `delete-account/` — personal-data deletion instructions

## Free hosting

Create a separate public GitHub repository named `underseen-pages`, then copy the **contents** of this folder into the root of that repository. Enable GitHub Pages with:

`Settings → Pages → Deploy from branch → main → / (root)`

The resulting URLs will be:

- `https://allanzico.github.io/underseen-pages/privacy/`
- `https://allanzico.github.io/underseen-pages/terms/`
- `https://allanzico.github.io/underseen-pages/support/`
- `https://allanzico.github.io/underseen-pages/delete-account/`

Review the contact details and policy wording before publishing. These are app-ready drafts, not legal advice.
